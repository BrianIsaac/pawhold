# The fictional practice

Every judge's session is given its own copy of this practice (decision D2),
seeded by `seedFictionalPractice` in `index.ts` through U1's seed seam.

- **Name**: "Hollins Lane Veterinary Surgery", D2's working name. Checked on
  12 October 2026: Companies House has no company of that name ("No results
  found" for "Hollins Lane Veterinary"; Hollins Lane is a street name used by
  property companies), and a web search finds no practice of that name. The
  RCVS Find a Vet register could not be read without running its scripts, so
  the RCVS check is still owed before the repository goes public.
- **Price list**: `price-list.csv`, 87 items across plan 3.3's eight
  categories, unit prices in pence including VAT. Written for this entry from
  the shape of published UK small-animal lists; not copied from any
  practice's list, and not a statement of what any practice charges.
- **Threshold**: the Order's £500 including VAT, the default.
